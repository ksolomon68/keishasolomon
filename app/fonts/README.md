# Bundled web fonts

These are the unchanged Latin-subset WOFF2 assets from the repository's previous committed Next.js build. They keep the existing typefaces available without build-time Google Fonts requests. The original font names, weight ranges and OFL notices are retained; each family has its license alongside it.

| Typeface | Previous committed asset | Local file |
| --- | --- | --- |
| Fraunces, 100–900 | 6e8c7cb283336a9d-s.p.woff2 | fraunces-latin.woff2 |
| Instrument Sans, 400–700 | 26d0ba92e140f0dc-s.p.woff2 | instrument-sans-latin.woff2 |
| JetBrains Mono, 100–800 | bb3ef058b751a6ad-s.p.woff2 | jetbrains-mono-latin.woff2 |
| Pinyon Script, 400 | 6c32053678f0295c.p.woff2 | pinyon-script-latin.woff2 |

Official license sources: `https://raw.githubusercontent.com/google/fonts/main/ofl/<family>/OFL.txt`, with family directories `fraunces`, `instrumentsans`, `jetbrainsmono`, and `pinyonscript`. No font files were modified. Additional language subsets can be bundled if the platform is localized.
