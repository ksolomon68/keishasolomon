Session 3: Executive triage and time evidence
THE AI EXECUTIVE SANDBOX — EVOBRAND Concepts

PURPOSE
Build a repeatable triage workspace that turns fictional requests into a checked action list. Measure the complete task, including review.

BEFORE YOU PASTE
Use fictional or explicitly approved examples. Do not paste private customer, employee, health or financial records into public AI tools. Follow your organization's tool and data rules. Treat outputs as drafts; a person verifies facts and approves external actions.

STARTER PROMPT
Triage these fictional requests using only this priority policy: [policy]. Return priority, action, owner, deadline, evidence and uncertainty. Leave missing fields unknown. Flag conflicting instructions for human review; do not resolve them silently. Do not send, schedule, delete or update anything. Requests: [examples].

TEST CASES
1. Routine: five fictional requests with known owners and deadlines.
2. Missing information: two requests have no deadline; one has no owner.
3. Conflict: two notes give different deadlines for the same task. The output must flag the conflict for a person to resolve.

TRANSFER CHALLENGE
Run three comparable trials. Calculate net savings = baseline minus (preparation + AI run + review + correction). Do not double-count overlapping time. Report quality failures alongside time.

SAVE AND REVIEW
Keep your own copy and follow the workbook submission instructions. Do not include passwords, private records or secret URLs.
